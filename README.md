# GardenKey PILOT V30

This repository is the clean production baseline for the GardenKey pilot.

## Public pages
- `index.html` — homepage and browsable plant library
- `plant.html` — shared plant profile
- `create.html` — tester draft submission
- `myplants.html` / `myplant.html` — personal plant records
- `pot.html`, `border.html`, `seedling.html` — garden trackers

## Admin pages
- `admin.html` — library record builder
- `admin-review.html` — review queue

## Core data
- `plants.json` — complete shared plant library, including `GK-PAR-001` Parahebe
- `personal-drafts.json` — tester-specific draft records
- `testers.json` — tester identities
- `user-plants.json` — repository submission/review data

All future releases should be built from this V30 baseline and delivered as one complete replacement ZIP.
