# GardenKey PILOT V29.1

Final pre-testing stability release.

## Changes
- Removed the cross-tester import block. A personalised NFC draft link is now authoritative, allowing Dave to test several testers' tags on one phone without deleting manually created plant records.
- Kept duplicate-safe imports: reopening the same draft returns to the existing saved record rather than creating another copy.
- Widened the Nickname field on mobile and retained responsive field sizing.
- Corrected tester links for Elaine, Eimear, Christine, Karen and Ann Campbell.
- Added Ann Campbell to the tester registry as `TST-ANN-009`.
- Retained one master `personal-drafts.json` with nine prepared draft records.
- Updated Home, My Plant, Pot and Border version labels to `PILOT V29.1`.
- Kept clean first-use Pot and Border pages and browser-only storage notices.

## Pilot freeze
After deployment, only critical defects should be changed before feedback is collected. New ideas should go into the post-test backlog.
