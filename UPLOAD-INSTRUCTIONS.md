# GardenKey V27 upload instructions

This ZIP is deliberately packaged with the website files at the top level.

1. Extract the ZIP on your device or computer.
2. Open the extracted folder.
3. Upload/replace the individual files in the root of the `Gardenkey-mvp` GitHub repository.
4. Do not upload a containing `GardenKey-V27` folder as a subfolder.
5. Wait 1–3 minutes, then refresh GitHub Pages. A private/incognito tab is useful for checking the live version.
6. Confirm the home or plant page shows `PILOT V0.27`.

To import Brian's Aeonium onto Dave's current browser/device, open once:

`myplant.html?draft=GK-DRAFT-009436`

Full live URL:

`https://davewalsh45pro.github.io/Gardenkey-mvp/myplant.html?draft=GK-DRAFT-009436`

After import it appears in My Plants as `Brian's Aeonium`. Opening the link again reopens the same record and does not duplicate it.
