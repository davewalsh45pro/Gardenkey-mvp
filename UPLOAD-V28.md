# GardenKey V28 tester update — upload instructions

This update contains six files to replace or add in the root of the `Gardenkey-mvp` repository:

- `index.html`
- `plant.html`
- `pot.html`
- `border.html`
- `myplant.html`
- `personal-drafts.json`

## Upload on GitHub

1. Open `https://github.com/davewalsh45pro/Gardenkey-mvp`.
2. Tap **Add file** and then **Upload files**.
3. Select all six files listed above. Upload the files themselves, not the containing folder or ZIP.
4. GitHub should show five existing files being replaced and `personal-drafts.json` being replaced with the expanded version.
5. In the commit message box enter: `Add V28 tester experience and personal plants`.
6. Tap **Commit changes**.
7. Wait 1–3 minutes for GitHub Pages to redeploy.
8. Open the homepage in a private/incognito browser tab and confirm it shows `PILOT V0.28`.

## Important pilot behaviour

Pot, border and personal-plant records are saved in the browser on the device that opens them. Elaine and Eimear should therefore scan their own tags on the phones/browsers they intend to use. This is separate per device and does not require an account, but it is not cloud syncing.
